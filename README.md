# Penguin Roastory · 企鹅烘焙

一套面向咖啡烘焙师的简单订单工作台。

[打开烘焙工作台](https://penguinroastory.minoscao.chatgpt.site)（仅所有者可访问）。

## 已实现

- 烘焙订单：创建订单，选择客户、豆子和烘焙方案；搜索并按状态筛选。
- 豆子档案：新增、编辑豆子，为每款豆子保存多套烘焙方案与曲线关键点。
- 客户档案：保存客户名称、联系方式和口味偏好。
- 已完成订单：完成即交付，保留历史参数和操作时间。

订单流程：**等待烘焙 → 正在烘焙 → 已完成**。

本版不管理库存，不连接或控制烘焙设备。每张订单使用一款豆子和一套方案。数据保存到数据库，历史订单的参数不会随方案修改而变化。

使用步骤见 [基础版本说明](docs/基础版本说明.md)。网页源代码在 [app](app)，开发说明见 [DEVELOPING.md](app/DEVELOPING.md)。协作与默认推送约定见 [AGENTS.md](AGENTS.md)。
