# 网页项目

继承上级 AGENTS.md 的中文沟通和默认 GitHub 推送约定。

用户已确认订单、豆子规格、库存、合并烘焙和发货主线。订单创建时扣减相应规格库存；烘焙完成与发货签收分别记录。物流自动查询、账务和设备控制暂不实现。

此目录是 Sites 应用根目录。使用 pnpm，保留 lockfile 和供应链安全策略。数据保存在 D1，不把浏览器存储当作业务数据来源。

历史订单保留客户名称、豆子名称和完整烘焙方案快照。修改档案和方案不应改变既有订单。

集成测试只允许使用本地地址。测试后用 tests/cleanup-local.py 清理本次产生的确切测试记录，不清空用户数据库。
